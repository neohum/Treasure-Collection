# 역사 보물도감 (Treasure Codex)

초등학교 5학년 사회(역사) 교육과정에 맞춘 디지털 보물도감 웹 애플리케이션(PWA)입니다.
수업 차시마다 배운 핵심어를 입력하거나 유물 사진을 등록하여 시대별 대표 보물 20종을 수집하고, 학생 소감 작성, 도감 인쇄, 교사용 런처/클라우드스쿨 과제 전송을 지원합니다.

---

## 1. 크롬북 PWA 설치 및 오프라인 사용법

1. **크롬북 브라우저 접속**: Chrome 브라우저에서 배포된 도감 URL(또는 교실 LAN 허브 주소)로 접속합니다.
2. **앱 설치**: 주소창 우측의 **설치 아이콘(⊕)** 또는 브라우저 메뉴 `⋮` -> **'역사 보물도감 설치'**를 클릭합니다.
3. **오프라인 실행**:
   - 설치 후 크롬북 앱 서랍(런처)에 보물도감 아이콘이 등록됩니다.
   - 서비스 워커(`sw.js`)가 모든 화면과 에셋을 기기에 사전 캐싱(Precache)하므로, 교실 Wi-Fi가 끊기거나 인터넷이 없는 야외에서도 앱이 정상 실행됩니다.
   - 오프라인 상태에서 작성된 과제는 로컬에 안전하게 큐잉되며, 네트워크 복구 시 선생님께 전송할 수 있습니다.

---

## 2. 교사용 핵심어 맞춤 설정 및 빌드

학급 수업 진도나 교과서 출판사에 맞춰 보물 해금 정답(핵심어)을 교체할 수 있습니다.

1. **핵심어 정의 파일 준비**:
   - `content/keywords.json` 파일을 생성합니다 (템플릿: `src/data/keywords.example.json` 참고).
   - 각 유물 ID별로 정답으로 인정할 핵심어 목록을 작성합니다.
   ```json
   {
     "art_01": ["빗살무늬 토기", "빗살무늬토기", "신석기 토기"],
     "art_02": ["고인돌", "강화 고인돌", "탁자식 고인돌"]
   }
   ```
2. **빌드 실행**:
   ```bash
   pnpm install
   pnpm build
   ```
   - 빌드 과정에서 평문 핵심어는 SHA-256 단방향 해시로 변환되어 `dist/config.json`에 저장됩니다 (클라이언트 소스코드에 정답 평문이 노출되지 않음).
   - 서비스 워커(`dist/sw.js`) 및 정적 번들이 `dist/` 폴더로 출력됩니다.

---

## 3. all_market 교실 런처 번들 반입 절차

`all_market` 구름학교 런처의 교실 LAN 허브에 도감을 직접 반입하여 배포할 수 있습니다.

1. **번들 패키징**:
   ```bash
   pnpm pack:bundle
   ```
   - `dist/` 디렉터리의 허용 확장자 규칙 및 마켓 보안 감사를 검증하고, `dist/manifest.json`(`ToolDistributionManifest`) 및 무결성 해시(`integrityHash`)를 생성합니다.
2. **런처에 반입**:
   - 교사용 구름학교 런처 실행 -> **교실 도구** -> **[번들 가져오기]** 클릭.
   - 프로젝트의 `dist/` 폴더를 선택합니다.
   - 무결성 검증 통과 후 배포 스위치를 켜면 교실 LAN 학생들에게 즉시 배포 URL 및 QR 코드가 제공됩니다.

---

## 4. 개발 및 검증 명령어

```bash
# 의존성 설치
pnpm install

# 타입 검사
pnpm typecheck

# 단위 및 번들 무결성 테스트
pnpm test

# 프로덕션 빌드 (Config + Vite + Service Worker)
pnpm build

# 번들 패키징 및 무결성 검사
pnpm pack:bundle

# E2E 테스트 (Playwright)
pnpm e2e
```
