## 1. 주요 기능 및 특징

- **📶 완벽한 오프라인 작동 (Service Worker 캐싱)**:
  - 교실의 불안정한 Wi-Fi나 통신 장애 환경에서도 한 번 접속하면 100% 정상 작동합니다.
  - 네트워크 단절 시 상단에 "오프라인 모드" 알림 배너가 표시되며 학습이 중단되지 않습니다.
- **📱 크롬북 / 태블릿 / 스마트폰 앱 설치 (PWA)**:
  - 브라우저 상단 주소창이나 앱 내 **[📲 앱 설치]** 버튼 하나로 독립형 데스크톱/모바일 앱처럼 설치됩니다.
- **🏛️ 5학년 사회과 역사 20종 대표 유물 수록**:
  - 선사 및 고조선(3종), 삼국 및 가야(6종), 통일신라 및 발해(3종), 고려(3종), 조선(5종).
  - 유물 사진 등록 시 브라우저 내부에서 고효율 압축되어 로컬 저장소에 안전하게 보존됩니다.
- **🎓 구글 클래스룸 특화 기능**:
  - 학생 인적사항(학교, 학년, 반, 번호, 이름) 기재 기능.
  - **클래스룸 공유**: 교사/학생이 구글 클래스룸으로 즉시 링크를 공유할 수 있는 인텐트 연동.
  - **과제 요약 복사**: 클릭 한 번으로 전체 달성 현황과 학생의 큐레이터 소감이 클립보드에 복사되어 클래스룸 비공개 댓글에 바로 제출 가능.
  - **A4 도감 리포트 인쇄 / PDF 저장**: 웹 UI 요소를 숨기고 A4 제출용 양식과 선생님 확인 도장란이 포함된 포트폴리오 형태로 출력 및 PDF 다운로드 가능.
  - **JSON 데이터 백업/복원**: 학교 크롬북 ↔ 가정용 PC 간 데이터 이동 및 교사에게 파일 제출 가능.

## 2. 웹 호스팅 무료 배포 방법

본 프로젝트는 순수 정적 웹 기술(HTML5, Tailwind, Flaticon UIcons, Service Worker)로 제작되어 **서버 비용 0원**으로 무제한 학생들에게 배포할 수 있습니다.

### 방법 A: GitHub Pages (가장 권장)

본 저장소에는 `.github/workflows/deploy.yml` 자동 배포 워크플로우가 내장되어 있습니다.

1. 본 프로젝트 코드를 GitHub 저장소의 `main` (또는 `master`) 브랜치에 푸시합니다.
2. GitHub 저장소 페이지의 **Settings** ➔ **Pages** 메뉴로 이동합니다.
3. **Build and deployment** 항목의 **Source**를 `GitHub Actions`로 선택합니다.
4. 푸시 즉시 Actions가 실행되며 약 1분 후 배포 URL이 생성됩니다.
   - 예: `https://<깃허브-아이디>.github.io/<저장소-이름>/`
5. 이 URL을 구글 클래스룸 과제 링크로 등록하시면 됩니다!

### 방법 B: Vercel / Netlify / Cloudflare Pages

1. [Vercel](https://vercel.com) 또는 [Netlify](https://netlify.com)에 로그인합니다.
2. **Add New Project** ➔ 본 GitHub 저장소를 연결합니다.
3. 빌드 설정(Build Settings)은 모두 기본값(Empty/Static)으로 두고 **Deploy**를 클릭합니다.
4. 발급된 `https://xxx.vercel.app` 주소를 즉시 사용할 수 있습니다.

### 방법 C: 교실 내부망 오프라인 로컬 서버

외부 인터넷이 완전히 차단된 컴퓨터실이나 교실에서도 교사용 PC에서 즉시 서빙할 수 있습니다.

```bash
# 로컬 개발 및 테스트 서버 기동
npm start
# 또는
node scripts/serve.js
```
- 브라우저에서 `http://localhost:3000` 또는 교사용 PC의 사내 IP(`http://192.168.x.x:3000`)로 같은 공유기에 연결된 학생 크롬북에서 접속할 수 있습니다.

## 3. 구글 클래스룸 과제 등록 가이드 (교사용)

선생님께서 수업 시간에 구글 클래스룸에 과제를 개설하는 단계입니다:

1. **구글 클래스룸([classroom.google.com](https://classroom.google.com))**에 로그인하고 해당 학급 수업에 들어갑니다.
2. 상단 **[수업]** 탭을 클릭하고 **[+ 만들기]** ➔ **[과제]**를 선택합니다.
3. **과제 내용 작성**:
   - **제목**: `[사회] 5학년 역사 디지털 보물도감 유물 사진 수집 프로젝트`
   - **안내(선택사항)**:
     ```text
     안녕하세요, 5학년 여러분!
     이번 역사 단원에서 배운 대표 유물 20종의 사진을 모아 나만의 디지털 보물도감을 완성해 봅시다.

     [활동 순서]
     1. 아래 링크를 클릭하여 '디지털 보물도감'에 접속합니다. (크롬북 사용자는 상단의 [앱 설치]를 누르면 더 편리합니다)
     2. 상단 [학생 정보 입력]을 눌러 본인의 반, 번호, 이름을 등록합니다.
     3. 선생님이 공유해 준 유물 사진을 시대별로 도감에 등록하고, 유물을 보며 느낀 '큐레이터 한 줄 소감'을 정성껏 적어보세요.
     4. 수집 완료 후 [과제 요약 복사]를 눌러 비공개 댓글로 제출하거나, [도감 출력/PDF]를 눌러 PDF로 저장한 뒤 과제 파일로 첨부하여 제출하세요!
     ```
4. **링크 추가**:
   - 하단의 **[링크]** 아이콘을 클릭하고 배포된 보물도감 URL(예: `https://your-domain.github.io/...`)을 첨부합니다.
5. **유물 사진 자료 첨부**:
   - 학생들이 다운로드하여 도감에 등록할 시대별 유물 사진(20종 이미지)을 구글 드라이브 폴더 링크 또는 압축파일 형태로 과제에 함께 첨부합니다.
6. 우측 상단의 **[과제 만들기]**를 클릭하면 배포가 완료됩니다!

## 4. 학생 과제 수행 및 제출 3가지 방법

학생들은 본인의 상황이나 선생님의 제출 가이드에 맞춰 다음 3가지 방법 중 하나로 과제를 제출할 수 있습니다:

### 📄 방법 1: A4 도감 리포트 PDF 저장 후 과제 파일 제출 (가장 추천!)
1. 20종의 유물 사진과 소감을 도감에 모두 등재합니다.
2. 상단 우측의 **[도감 출력/PDF]** 버튼을 클릭합니다.
3. 브라우저 인쇄 창이 뜨면 **[대상]**을 `PDF로 저장`으로 변경합니다.
4. 상단에 학교, 반, 번호, 이름, 달성률, 확인 도장란 및 20개 유물 카드가 정리된 PDF 파일이 저장됩니다.
5. 구글 클래스룸 과제 화면에서 **[추가 또는 만들기]** ➔ **[파일]**을 눌러 저장된 PDF를 첨부하고 **[제출]**을 누릅니다.

### 📋 방법 2: 과제 요약 복사 후 클래스룸 비공개 댓글에 제출
1. 도감 상단의 **[과제 요약 복사]** 버튼을 클릭합니다.
2. 클립보드에 학생 정보, 총 달성률, 수집한 유물 목록 및 큐레이터 소감이 정리되어 자동 복사됩니다.
3. 구글 클래스룸 과제 화면 우측의 **[비공개 댓글]** 입력창에 `Ctrl + V`로 붙여넣고 전송한 뒤 **[완료로 표시]**를 누릅니다.

### 💾 방법 3: 도감 데이터(JSON) 백업 파일 제출
1. 상단 우측의 더보기(▼) 버튼을 누르고 **[데이터 백업 (JSON)]**을 클릭합니다.
2. `보물도감_홍길동_2026-09-04.json` 파일이 다운로드됩니다.
3. 클래스룸에 파일로 첨부하여 제출하면, 선생님께서 본인의 도감 앱에서 **[데이터 복원]**을 통해 학생의 도감을 그대로 열어보실 수 있습니다.

## 5. 크롬북 및 모바일 기기 PWA 앱 설치 방법

### 💻 크롬북 (Chromebook) 및 Chrome 브라우저
1. 보물도감 웹사이트에 접속합니다.
2. 브라우저 주소창(URL 바) 우측의 **앱 설치 아이콘(컴퓨터 모니터 모양)**을 클릭하거나, 헤더에 나타나는 반짝이는 **[📲 앱 설치]** 버튼을 클릭합니다.
3. "앱을 설치하시겠습니까?" 팝업에서 **[설치]**를 클릭합니다.
4. 크롬북 실행기(Shelf)에 '역사보물도감' 아이콘이 등록되며, 인터넷이 없는 상태에서도 독립 앱 창으로 즉시 열립니다.

### 📱 스마트폰 / 태블릿 (Android Chrome)
- 화면 상단 또는 하단에 나타나는 "홈 화면에 추가" 배너 또는 브라우저 메뉴(⋮) ➔ **[앱 설치]** 선택.

### 🍏 iPad / iPhone (iOS Safari)
- 하단 공유 버튼(네모 위 화살표 아이콘) ➔ **[홈 화면에 추가]** 선택.

## 6. 학교 네트워크 / 오프라인 교실 문제 해결

- **Q. 교실 Wi-Fi가 자꾸 끊깁니다. 작업한 내용이 날아가나요?**  
  **A.** 전혀 날아가지 않습니다! 모든 유물 사진과 큐레이터 소감은 학생 기기의 브라우저 내부 로컬 저장소(LocalStorage)에 실시간으로 즉시 암호화/저장됩니다. 또한 서비스 워커가 앱 리소스를 캐싱하고 있어 Wi-Fi가 끊겨도 오프라인 모드로 정상 작동합니다.

- **Q. 크롬북에서 등록할 사진 용량이 너무 커서 오류가 나지 않나요?**  
  **A.** 도감 내부의 자동 이미지 프로세서가 고용량 사진이라도 웹 표준 규격(최대 800px, JPEG 70%)으로 즉시 자동 압축하여 변환하므로 크롬북의 저장 공간을 거의 차지하지 않고 빠릅니다.

- **Q. 학교 컴퓨터실에서 작업하다가 집에 가서 이어서 하고 싶어요.**  
  **A.** 상단 우측 더보기 메뉴 ➔ **[데이터 백업 (JSON)]**을 클릭하여 USB나 구글 드라이브에 저장한 뒤, 집 컴퓨터에서 접속하여 **[데이터 복원 (JSON)]**을 누르면 작업하던 내용이 그대로 복원됩니다!
